# Agent entrypoint

When planning, implementing, reviewing, or deploying this repository, read [`docs/README.md`](docs/README.md) first. It defines document authority and points to the one owning document for each product, domain, data, AI, UI, operations, and acceptance contract. Read every owning document that applies to the task before changing code.

Treat material outside this repository as reference only. When it conflicts with the documents indexed by `docs/README.md`, the repository documents win unless the user explicitly changes a decision.

At the end of an implementation task, report the completed vertical slice, changed interfaces, tests actually run, AI model/effort and transmitted data when applicable, operational commands, and remaining risks. Do not claim completion without running the checks required by [`docs/06-acceptance.md`](docs/06-acceptance.md) for the affected stage.
