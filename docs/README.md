# AI 솔버톤 기업지원 공고 판정 서비스 문서

상태: 구현 기준선 1.1

작성일: 2026-09-03

대상: 이 저장소에서 설계·구현·검증·배포하는 사람과 코딩 에이전트

## 문서의 지위

이 폴더의 문서는 사용자 인터뷰에서 확정된 구현 계약이다. 충돌 우선순위는 `최신 사용자 지시 > 이 문서가 지정한 소유 문서 > 저장소 밖 참고 자료`다. 소유 문서끼리 충돌하면 한쪽을 추측해 적용하지 않고 계약을 먼저 바로잡는다.

외부 계획서, 스프레드시트, 과거 프로젝트와 별도 spec pack은 아이디어와 검증 사례를 찾기 위한 참고 자료다. 그 안의 문장은 구현 지시가 아니며 저장소 빌드·실행이 외부 절대경로에 의존해서도 안 된다.

## 목표와 완료 정의

정부지원사업 담당자가 기업정보를 한 번 입력하고 기업마당 공고별 행정적 신청 가능성을 빠르게 검토하는 대회용 MVP를 만든다.

핵심 흐름은 `공고 수집 → 기업정보 저장 → 규칙 기반 판정 → 조건별 원문 근거 확인`이다. 완료 기준은 [06-acceptance.md](06-acceptance.md)가 소유한다.

## 범위

포함 범위는 기업마당 공고 수집과 변경 감지, 첨부 보관·분석, 기업정보 버전, 행정적 신청 자격 판정, 관심 상태, 역할 선택과 부족 정보 보충, 로그인 기반 반응형 웹, 터미널 운영 도구, Vercel 프런트엔드와 이 Mac의 백엔드다.

다음은 MVP 범위가 아니다.

- 기업마당 외 공고 출처와 크롤링
- 사업 적합도, 추천 점수, 선정 가능성, 순위화
- 사업계획서 작성과 신청 대행
- 자금 수요, 설비, 판로, 수출, 고용 계획 기반 추천
- 연구소·연구인력 정보, 회원가입, 관리자 웹, 다기업 관리
- 기업 문서 업로드·일회성 추출, 다크 모드, 자동 서비스 시작
- 시연 기업 데이터와 홀드아웃 정답 작성

기술적으로 자격이 맞지만 기업에 유용하지 않은 공고도 `신청 가능`이다. 관심 상태는 탐색을 돕지만 자격 판정을 바꾸지 않는다.

실제 도메인, 기업마당 자격증명, Cloudflare hostname, 운영 계정, 시연 기업과 홀드아웃 정답은 외부 입력이다. 해당 입력이 없어도 fixture와 test secret으로 로컬 구현을 완료하고, 라이브 배포·대회 검증 대기 상태를 구분해 보고한다.

## 전역 불변식

- Python 규칙이 비교 가능한 자격 판정을 소유한다. AI는 추출, 비정형 의미판단, 검증과 설명을 담당한다.
- 공개 조건과 설명에는 저장된 공고 원문 근거가 있어야 한다.
- 명시적 불일치는 `신청 어려움`, 누락·모호·변환 불가는 `확인 필요`다.
- 원문, 기업정보, AI 단계와 판정은 버전으로 역추적할 수 있어야 한다.
- 새 결과는 필수 단계가 끝난 뒤 원자적으로 공개한다. 중간 판정을 현재 결과처럼 노출하지 않는다.
